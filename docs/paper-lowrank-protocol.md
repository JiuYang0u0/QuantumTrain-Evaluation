# 低秩直接訓練：更強的古典壓縮基準

問題：匹配預算的固定隨機特徵（古典rf）明顯不如量子版。但凍結隨機投射只是一種設計；更強的古典壓縮方法可能縮小差距。本輪改用**低秩直接訓練**。

## 方法

直接把目標 CNN 的權重矩陣以 rank-r 因子表示並訓練，沒有生成器、沒有量子電路：

| 權重矩陣 | 形狀(降為2D) | rank-r 參數 |
|---|---|---|
| conv1.weight | (8, 25) | r·(8+25) |
| conv2.weight | (12, 200) | r·(12+200) |
| fc1.weight | (20, 192) | r·(20+192) |
| fc2.weight | (10, 20) | r·(10+20) |
| biases | 50 | 50 |

每層有效 rank = min(r, min(shape))。可訓練參數量 = 487·r + 50：

| r | 參數 | 相對6690 |
|---|---:|---:|
| 1 | 537 | 8.03% |
| 2 | 1024 | 15.31% |
| 3 | 1511 | 22.59% |
| 4 | 1998 | 29.87% |
| 6 | 2972 | 44.42% |

初始化：對目標模型自身初始化的每個權重矩陣取 SVD，用前 r 個成分做平衡初始化；全秩時可精確重建。

## 協定

10000 train／200 validation（同 QT 控制索引）、12000 updates、batch128 有放回、LR1e-4、eval 每 100、節點 4000/8000/12000、seeds 11/22/33，rank ∈ {1,2,3,4,6}，共 15 runs。未使用 official test；每 run 具完整 latest.pt 續訓。

## 解讀界線

- r=1（537）對比 QT16（457）；r=3（1511）對比 QT106（1627）。
- 低秩是古典壓縮的一種，不涵蓋剪枝、量化等；結論限於此方法與此重建設定。
- 同 updates 不等於同計算成本；低秩直接訓練遠快於量子模擬。
- 200筆開發validation、三seed；不構成量子優勢或量子無效的結論。
