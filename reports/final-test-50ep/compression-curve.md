# r3 量子生成器的壓縮曲線(官方 MNIST test,23,450 updates)

完整資料 54,000 train／6,000 validation、23,450 updates(≈50 epochs)、官方 test 只評估一次。所有生成器都把 610／6690 個目標 CNN 權重建模為「電路特徵 → 傳統映射網路 → 權重」;QT 與低秩都只公開陳列獨立可訓練參數數量與官方 test 結果,並保留原始訓練腳本。訓練全程未讀官方 test。

## 觀察

1. 同樣 24.32% 的可訓練參數,QT106(96.08%)比低秩最高(1511,89.14%)高 6.94pp,且比低秩 1998(29.87%,93.68%)少約 19% 參數仍高 2.40pp——**在本設定下,量子電路的特徵擴張確實比低秩分解更「參數有效率」**。
2. QT16(6.83% 參數)達 85.89%,顯示極端壓縮仍然可行;這與論文中「用 polylog 個參數生成 M 個權重」的機制一致。
3. 純古典低秩在 537–1024 參數時只有 34–72%,證實該區間的壓縮不是任意小模型都能做到。

## 限制(重要)

- 單 seed、23,450 updates、r3 假設、小 CNN、train-carved validation、CPU 模擬。
- 未測 CIFAR-10、19 qubits、更深 blocks(論文 up to 323)、utility-scale 動態電路。
- 未比較 mobile 或 large-language-model 規模的壓縮。
- CPU 成本高昂;真實 QPU 可行性、 shots、gate error 完全未處理。
- 本文件是單次官方 test 評估;若之後繼續用它調整設定,就不再是凍結評估。
